本地开发
1. npm install
2. 复制 .env.example 为 .env，填入 Supabase 项目 URL 和 anon key
3. 在 Supabase SQL Editor 中执行 supabase/schema.sql
   若登录 admin/admin 报 Invalid username or password，再执行 supabase/fix-rls.sql
4. npm run dev
5. 打开 http://localhost:5173 ，点击导航「对账平台 / Reconcile」进入登录页

演示账号
- 老板：admin / admin
- 员工：在 Admin Dashboard → Employee Management 中创建

对账平台路由
- /reconcile/login — 登录
- /reconcile/admin — 老板后台
- /reconcile/employee — 员工后台

部署到 GitHub Pages（公网访问）
1. GitHub 仓库 → Settings → Secrets and variables → Actions → New repository secret
2. 添加两个 Secret（名称必须完全一致）：
   - VITE_SUPABASE_URL = https://你的项目.supabase.co
   - VITE_SUPABASE_ANON_KEY = Supabase 的 anon public key 或 publishable key
3. push 到 main 或 v_1.0 分支，等待 Actions 部署完成
4. 访问 https://thinkpipeai.tech/reconcile/login

说明：.env 只在本地有效，不会上传到 GitHub。公网版本在 CI 构建时从 Secrets 注入环境变量。

公网登录异常排查
- 若报 Supabase is not configured，但换浏览器能登录：原浏览器缓存了旧版 JS，请硬刷新（Cmd+Shift+R）或清除 thinkpipeai.tech 站点数据
- 部署新版本后建议硬刷新一次，确保加载最新 index.html
