本地开发
1. npm install
2. 复制 .env.example 为 .env，填入 Supabase 项目 URL 和 anon key
3. 在 Supabase SQL Editor 中执行 supabase/schema.sql
   若登录 admin/admin 报 Invalid username or password，再执行 supabase/fix-rls.sql
4. npm run dev
5. 打开 http://localhost:5173 ，点击导航「对账平台 / Reconcile」进入登录页

演示账号
- 老板：admin / admin
- 员工：在 Admin Dashboard → Employee Management 中创建

对账平台路由
- /reconcile/login — 登录
- /reconcile/admin — 老板后台
- /reconcile/employee — 员工后台
